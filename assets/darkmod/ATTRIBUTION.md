## Modifications

The models in this folder have been:

- Converted from the original Doom 3 MD5/ASE formats to glTF/GLB
- Had collision and shadow geometry retained as hidden materials
- Had texture paths updated for the glTF format

Any derivative models created from these assets must also be released under
CC-BY-NC-SA 3.0.

## Model List

The following model categories are included:

- **weapons/**: Swords, axes, maces, hammers, staves, spears, bows, arrows
- **tools/**: Pickaxe, smithy hammers
- **wearables/**: Shields, quivers
- **decorative/**: Wall trophies, ornamental items
- **loot/**: Treasure items, exotic materials
- **junk/**: Broken weapons, debris
- **misc/**: Miscellaneous props
